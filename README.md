## Запуск проекта через Docker
### Компоненты для установки
* установить Docker Desktop

### Подготовка окружения
* скопировать все поля из .env.template
* перенести их в .env и заполнить реальными значениями

### Сборка образов
* выполнить команду ``docker compose build``

### Запуск контейнеров
* выполнить команду `docker compose up`

## Работа с приложением
### Применение миграций
* выполнить команду `docker compose exec web python manage.py migrate`
* выполнять строго после запуска контейнеров
### Адрес приложения:
    http://localhost:8000
### Просмотр логов
* `docker compose logs`
* в реальном времени - `docker compose logs -f`
* логи конкретного сервиса - `docker compose logs -f service_name`
### Остановка контейнеров:
* для остановки запущенного в текущем терминале Compose используется Ctrl+C
* для остановки и удаления контейнеров — `docker compose down`
